# Руководство пользователя Claude Authorization Bot

> **Простое руководство по использованию бота для получения кодов авторизации Claude Code**

---

## Что это за бот?

Claude Authorization Bot автоматизирует процесс получения кодов авторизации для Claude Code. Вместо того чтобы вручную открывать email, переходить по ссылкам и копировать коды, вы просто отправляете команду боту и получаете готовый код прямо в Telegram.

### Основные возможности

✅ Автоматическое получение кодов авторизации Claude
✅ Работает в групповых чатах и личных сообщениях
✅ Безопасное хранение сессий для каждого чата
✅ Простые команды для всех операций

---

## Быстрый старт

### 1. Первое использование (настройка)

**Если вы администратор группы**, вам нужно один раз настроить бота:

1. **Добавьте бота в вашу группу** или начните диалог в личных сообщениях

2. **Инициализируйте сессию** командой:
   ```
   /init_session your.email@example.com
   ```

   Замените `your.email@example.com` на email от вашего Claude аккаунта.

3. **Подождите ответа бота**:
   ```
   🔄 Initializing session for your.email@example.com.
   Please wait for the authorization link request...
   ```

4. Через несколько секунд бот попросит ссылку из email:
   ```
   📧 Email sent! Please send me the authorization link from your inbox.
   ```

5. **Откройте ваш email** и найдите письмо от Claude с темой о входе в аккаунт

6. **Скопируйте ссылку авторизации** из письма (она начинается с `https://claude.ai/auth/...`)

7. **Отправьте ссылку боту** (просто вставьте в чат)

8. **Дождитесь подтверждения**:
   ```
   ✅ Session initialized successfully!
   You can now use /get_code to extract authorization codes.
   ```

**Готово!** Теперь все участники группы могут получать коды авторизации.

---

### 2. Регулярное использование (получение кодов)

Когда Claude Code просит вас авторизоваться:

1. **Скопируйте URL авторизации** из Claude Code. Он выглядит примерно так:
   ```
   https://claude.ai/auth/authorize?client_id=abc123...&redirect_uri=...
   ```

2. **Отправьте команду боту**:
   ```
   /get_code https://claude.ai/auth/authorize?client_id=abc123...
   ```

3. **Подождите 5-10 секунд**. Бот ответит:
   ```
   🔄 Extracting authorization code...
   ```

4. **Получите код**:
   ```
   ✅ Authorization code: `ABC123XYZ789`
   ```

5. **Скопируйте код** (кликните на него для автоматического копирования) и вставьте в Claude Code

**Вот и всё!** 🎉

## Все доступные команды

### `/init_session <email>`

**Назначение:** Первоначальная настройка бота для вашего чата/группы
**Кто может использовать:** Только администраторы группы
**Когда использовать:** Один раз при первой настройке

**Пример:**
```
/init_session john.doe@company.com
```

**Что происходит:**
1. Бот отправляет запрос на авторизацию на указанный email
2. Вы получаете ссылку в письме
3. Отправляете ссылку боту
4. Бот сохраняет сессию для вашего чата

---

### `/get_code <authorization_url>`

**Назначение:** Получение кода авторизации для Claude Code
**Кто может использовать:** Любой участник группы
**Когда использовать:** Каждый раз когда нужен код авторизации

**Пример:**
```
/get_code https://claude.ai/auth/authorize?client_id=abc&redirect_uri=...
```

**Что происходит:**
1. Бот открывает вашу сохраненную сессию
2. Переходит по ссылке авторизации
3. Извлекает код
4. Отправляет вам готовый код

**Время выполнения:** обычно 5-10 секунд

---

### `/health`

**Назначение:** Проверка статуса бота и системы
**Кто может использовать:** Любой участник
**Когда использовать:** Если что-то не работает или для проверки

**Пример:**
```
/health
```

**Ответ:**
```
✅ Bot Status

• Database: ✅ Connected
• Active sessions: 5
• Pending tasks: 2
• Worker: Running
```

## Частые вопросы (FAQ)

### ❓ Нужно ли каждому участнику группы настраивать свою сессию?

**Нет!** Одна сессия работает для всей группы. Администратор настраивает сессию один раз командой `/init_session`, и все участники могут использовать `/get_code`.

---

### ❓ Могу ли я использовать бота в личных сообщениях?

**Да!** Бот работает как в группах, так и в личных чатах. В личном чате вы являетесь администратором, поэтому можете сами настроить сессию.

---

### ❓ Сколько времени действительна сессия?

Сессия остается активной пока вы её используете. Если долго не пользоваться (несколько недель), может потребоваться переинициализация через `/init_session`.

---

### ❓ Можно ли использовать разные email для разных групп?

**Да!** Каждая группа/чат имеет свою изолированную сессию. Вы можете настроить разные email для разных групп.

---

### ❓ Безопасно ли использовать бота?

**Да!** Сессии хранятся изолированно для каждого чата, доступ к `/init_session` имеют только администраторы группы, все данные защищены.

---

### ❓ Что делать если бот не отвечает?

1. Проверьте командой `/health` - работает ли система
2. Подождите 1-2 минуты - возможно бот временно перегружен
3. Попробуйте команду еще раз
4. Обратитесь к администратору бота

---

### ❓ Можно ли использовать бота с несколькими Claude аккаунтами?

В рамках одной группы - нет. Одна группа = одна сессия = один email. Но вы можете создать несколько групп с разными email адресами.

## Возможные проблемы и решения

### 🔴 "Session not found. Please initialize with /init_session first"

**Причина:** Сессия для вашего чата еще не настроена
**Решение:** Администратор группы должен выполнить `/init_session <email>`

---

### 🔴 "Failed to extract code. Session might be expired"

**Причина:** Сессия устарела или невалидна
**Решение:**
1. Попробуйте команду `/get_code` еще раз
2. Если не помогло - переинициализируйте сессию через `/init_session`

---

### 🔴 "Invalid authorization URL format"

**Причина:** Неправильный формат ссылки
**Решение:** Убедитесь что вы копируете полную ссылку из Claude Code, она должна начинаться с `https://claude.ai/auth/authorize?`

---

### 🔴 "Task timed out"

**Причина:** Операция заняла слишком много времени
**Решение:**
1. Подождите 1 минуту
2. Попробуйте команду еще раз
3. Если повторяется - обратитесь к администратору

---

### 🔴 "Permission denied. Only group admins can initialize sessions"

**Причина:** Вы пытаетесь выполнить `/init_session` не будучи администратором
**Решение:** Попросите администратора группы настроить сессию

## Альтернатива: CLI (Command Line Interface)

Помимо Telegram бота, проект предоставляет интерфейс командной строки (CLI) для получения кодов авторизации напрямую с компьютера, без использования Telegram.

### Когда использовать CLI?

- ✅ Когда нет доступа к Telegram
- ✅ Для автоматизации и скриптов
- ✅ При работе с личными сессиями
- ✅ Для разработчиков и DevOps

### Быстрый старт с CLI

**1. Создать сессию:**
```bash
python -m bot.cli account init-session ./my-session user@example.com
```

**2. Обработать ссылку из email:**
```bash
python -m bot.cli account process-login ./my-session "https://claude.ai/login?token=..."
```

**3. Получить код авторизации:**
```bash
python -m bot.cli account get-code ./my-session "https://claude.ai/auth/authorize?..."
```

### Основные команды CLI

```bash
# Управление сессиями
python -m bot.cli account init-session <path> <email>
python -m bot.cli account process-login <path> <url>
python -m bot.cli account get-code <path> <url>
python -m bot.cli account delete-session <path>

# Просмотр сессий бота
python -m bot.cli account list-chats

# Проверка здоровья системы
python -m bot.cli health
```

### Преимущества CLI

- **Гибкость** - создавайте сессии в любом месте на диске
- **Независимость** - не требует запущенного Telegram бота
- **Скриптуемость** - легко интегрируется в автоматизацию
- **Совместимость** - может использовать сессии созданные ботом
